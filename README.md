                                                      # Marketing-campaign-performance-Analysis

                                                       ## Project Overview
This project demonstrates an end-to-end Marketing Analytics solution developed to analyze campaign performance, customer behavior, product performance, and marketing ROI. The project follows the complete analytics lifecycle, including data cleaning, SQL analysis, KPI development, and interactive dashboard creation using Power BI.


                                                   ##  Business Objectives
•	Monitor campaign performance.
•	Analyze marketing ROI.
•	Evaluate customer behavior.
•	Identify high-performing products.
•	Measure channel effectiveness.
•	Support data-driven decision-making.

                                                      ## Business Insights
                                                      
•	Social Media generated the highest revenue.
•	Premium customers contributed the majority of sales.
•	ROI varied significantly across campaigns.
•	Product categories showed different performance levels.
•	Customer Lifetime Value was highest for Premium customers.
