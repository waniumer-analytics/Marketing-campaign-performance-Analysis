  ## Marketing-campaign-performance-Analysis

# Project Overview
                                                       
This project demonstrates an end-to-end Marketing Analytics solution developed to analyze campaign performance, customer behavior, product performance, and marketing ROI. The project follows the complete analytics lifecycle, including data cleaning, SQL analysis, KPI development, and interactive dashboard creation using Power BI.


# Business Objectives

1. 	Monitor campaign performance.
2. Analyze marketing ROI.
3. Evaluate customer behavior.
4. Identify high-performing products.
5. Measure channel effectiveness.
6. Support data-driven decision-making.

# Tools Used

1. Microsoft Excel.
2. Python (Pandas, NumPy).
3. MySQL.
4. Power BI.
5. DAX.
6. Power Query
